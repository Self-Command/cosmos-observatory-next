# 面板表面重设计

2026-10-11，用户确认 fda950b 安装后面板背景仍闪烁，要求重新设计。此前仅证明 SVG 节点及 DOM 未重建，不能证明最终合成画面稳定。

本轮删除每张卡片的 SVG 背景、HTML 注入、背景资源缓存及尺寸监听；删除透明覆盖规则和 backdrop-filter，统一为官方 Card 上的一套 CSS 表面。底色始终不透明，圆角及边框直接作用于卡片，标题分隔线由 CSS 绘制。尺寸变化不再触发另一套背景几何更新。

配置键 panelOpacity 继续接收原值，范围和默认值保持一致，显示名称改为“面板背景深度”。数值调节不透明底色的明度；不再使动态图谱透过卡片。圆角、边框强度、字号和密度继续独立生效。

验证全部运行于 Actions：panel-surface.spec.ts 对实际截图的空白内边距逐像素检查，动态图谱和连续事件保持运行。测试覆盖 0.2、0.5、1 三种深度，六张卡片与双视图十二张卡片，高 DPI，拖动及缩放。亮色交替底层用于放大透底问题；临时把一张卡片设为透明的负对照必须被检测为失败。原有四十八次鼠标缩放、覆盖布局、设置、宿主和耐久检查继续执行。

验证结果以本轮 Actions、截图像素报告和同包 CANDIDATE-VERIFICATION.json 为准。本文件在构建前不声明通过。

首轮截图采样包含世界地图图标的正常外发光，偏差为 2–3，严格阈值正确阻止了交付。采样移到所有面板标题左侧的空白内边距，避开发光内容及最大圆角；允许偏差仍为 1，透明负对照及亮色交替底层保留。

四种原生组合和浏览器单视图在修正采样后通过；双视图高 DPI 连续全窗口截图触及 90 秒测试时限。截图改为覆盖全部面板的区域，并为像素测试关闭录像、保留 180 秒时限；动态图谱、DPI、事件更新、负对照及像素阈值均保持。完整图谱画面另存截图，原有鼠标录像仍执行。

完整回归中，双视图高 DPI 在浏览器内 PNG 解码阶段仍触及时限，独立序列通过。像素测试改用 pngjs 在 Node 测试进程读取截图，不再在两个繁忙的 WebGL 视图旁创建解码 Canvas；pngjs 仅是测试依赖，锁文件由 Actions 生成，插件运行包不新增依赖。
