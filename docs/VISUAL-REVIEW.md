# 全部 UI 视觉复检

依据原批准 SVG 的宇宙背景、世界配色、球壳、光晕、蜘蛛和六面板风格，保留其视觉参数；文字与交互控件采用自适应 DOM 排版。自动化截图仅提供证据，逐张人工审阅通过后才关闭视觉需求。

复检标准：标题与正文清晰，控件与文字对齐，间距和边框一致，长中文标题及路径可换行或有可访问的完整文本；内容能滚动，弹窗和恢复按钮不超出视图；不同字号及 DPI 不出现字形拉伸、重叠、裁切或遮挡。下拉层、悬停提示和菜单属于当前视图，键盘焦点可见并可关闭和返回。
