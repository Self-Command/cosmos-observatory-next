# 需求复检与修复记录

## 2026-10-11 实际使用反馈修复

用户反馈面板背景闪烁、明显卡顿及链接覆盖排版混乱。修复面板 SVG 重复注入全局样式、重复设置背景 DOM、覆盖环在每个事件上重启动画、鼠标每个移动事件重绘全部节点与三角形拾取的开销。面板沿用批准 SVG 的单个渐变与外壳，资源 ID 按视图隔离；关联覆盖改为稳定 SVG 环和响应式两列布局，数据按文件及关系变化更新。三维配置与事件更新分离，已有可见目标复用节点分配，悬停合并至每帧一次并用 Three.js 球面交点完成拾取。

验收新增 ui-stability：40 次持续事件期间八个背景保留 DOM、零背景变更、零图形重建；200 个鼠标事件合并；四种宽度/字号下覆盖百分比居中、五项明细入口保留且不横向溢出。仍须以本次 Actions 实测结果与截图确认，旧候选的成功记录不代表本次问题已验证。

本次按 DEVELOPMENT-PLAN.md 和 2026-10-10 批准的全部缺项补齐计划执行。COMPLETION-MATRIX.md 登记 50 个必需项。安装构建的提交、构建运行和完整校验由同包 BUILD-INFO.json、CANDIDATE-VERIFICATION.json、FILE-SHA256SUMS 确定；较早提交的通过结果只用于修复追踪。
