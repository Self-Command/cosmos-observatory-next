# 原 SVG 源码复用契约

原文件 `assets/dashboard-spheres-v2.svg` 保持字节不变，由 Actions 验证固定 SHA-256。实现入口为 `src/scene/reference.ts`，直接以文本导入原 SVG，再用 DOMParser 解析。

| 原 SVG 内容 | 实际复用 | 真实数据边界 |
| --- | --- | --- |
| 世界 transform 与名称 | 已识别目录采用相应初始布局模板 | 世界来自实际一级目录；新目录有独立位置，不固定七个 |
| 球轮廓半径、节点 cx/cy/r/opacity | 文件 SphereGeometry 的布局、大小与透明度 | 每个显示文件球绑定真实文件；演示节点 ID 不进入索引 |
| 世界标题颜色及副标题 | 默认身份色和标题样式 | 显式用户覆写优先，改名保持稳定 ID |
| 轨道 ellipse | Three 曲线与三维轨道角度 | 装饰轨道不作为文件链接 |
| 宇宙渐变、星点 | 原 SVG 背景层及 Three 背景纹理色阶 | 无业务统计 |
| 六面板 rect、标题与分隔线 | 直接克隆原向量代码，作为 shadcn Card 的底板 | Card 内容由实际事件、世界、关系、检查证据驱动 |
| 顶栏与导航向量代码 | 直接克隆，替换世界数量、模型及运行状态 | 不保留 VISUAL DRAFT 或演示模型状态 |
| 示例边、示例数字和事件文字 | 不导入业务模型 | 真实关系只从 Obsidian 解析链接、登记属性与显式依赖获得 |

默认前视图使用原 1560×1120 坐标基准。三维深度加入到文件节点后，用透视补偿保持该视角的轮廓；镜头旋转会显示前后位置、遮挡和实际体积。稀疏目录不补造文件，文件数不同也不能复制演示节点数量。拖动后的用户布局和不同屏幕比例不强制回到原图。

Actions 同时生成原 SVG PNG、默认插件视图 PNG、交互后视图以及录像。用户视觉审阅和三维交互证据共同验收，不能凭单张 PNG 宣称完整三维，也不将全部业务数值与演示图逐像素相同作为通过条件。
