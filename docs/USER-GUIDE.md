# 使用指南（开发候选）

候选审阅前不自动安装到真实知识库。最终 ZIP 完整解压到 vault 的 `.obsidian/plugins/cosmos-observatory-next/`；保留 assets 子目录和许可文件。仅复制 main.js 会丢失蜘蛛模型。

启用插件后，点击侧栏轨道图标，或执行命令“打开宇宙观测台”。一个 Obsidian ItemView 内显示宇宙与控制台。首个观测面板打开时才读取目录、元数据并启动本地检查；面板打开期间，文件变化自动更新。最后一个观测面板关闭后立即停止巡查、轮询、事件监听和接收端口，并释放图形资源。仅启用插件不会扫描。再次打开时重新读取当前状态，关闭期间的变化只报告净变化，不补造过程记录。

- 大球名称来自实际一级目录。空目录显示空态，新目录职责待确认。小球对应真实文件；隐藏数量表示显示预算，不是文件丢失。
- 拖动背景旋转镜头，滚轮缩放。直接拖动任一世界的中心，只移动这个世界及其成员；其他世界中心保持原位。世界内没有索引文件时，中心显示拖动锚点，不计入文件数量。
- 文件小球可以各自拖动，关联节点会受力响应，松手后继续运动。右键可固定或解除固定。世界锁只限制世界排版，文件固定、动态暂停和面板锁分别生效。排版工具还提供 XYZ 平移及旋转；设置中的“独立世界”可精确输入三轴数值。
- 单击小球选择文件，双击打开，拖动不会打开。悬停显示名称、完整路径、类型和检查状态，即使常驻标签关闭也可使用。Escape 取消当前拖动，Home 复位镜头。
- 搜索支持世界、文件名、路径、空目录、库根和预算外文件。上下方向键选择，Enter 定位，Escape 清空。库根文件通过“实体”入口查看，没有库根球。
- 面板标题可以拖动，边与角可以缩放。标题按钮支持锁定、最大化与隐藏；底部可以重新显示。布局按当前 vault 保存。
- “动态”暂停图形和受力运动，“暂停巡查”停止新检查。历史入口提供前后快照、播放、暂停和倍速；面板打开的回放期间继续记录真实变化，历史操作与实时布局分开。返回实时后恢复当前索引与巡查；关闭全部观测面板后停止记录。
- 设置包含配色、世界三轴布局、节点层数、引力、斥力、碰撞、阻尼、线宽、背景、蜘蛛尺寸、巡查、模型路径、范围、面板和容量。数值与路径先保留草稿，Enter 或离开输入框时校验保存；失败会显示原因。配置可复制或通过 JSON 文件导入导出，一次校验并原子保存，凭据不导出。分组可恢复默认。

六面板和明细入口：事件可按世界、来源、会话、动作、状态及起止时间筛选；世界地图可定位、查看成员并配置职责、颜色和中心；链接覆盖可展开关联、孤立、跨球及未解析明细；热图支持来源、时间窗口及单元格事件；检查结果可筛选五种状态、规则、实体和世界并手动复查；当前关系可打开两端文件、遍历关联并返回上一个对象。顶部“系统”展示模型、模板、脚本及插件资产变化，“会话”展示接入诊断、会话和工具记录。

面板标题和正文使用正常排版，六列在空间不足时改为三列、两列或一列。面板滚动条隐藏，内容仍可用滚轮、触控板和键盘滚动。窗口临时缩小时会限位，恢复窗口后恢复原布局；设置提供面板尺寸限制与布局重置。所有弹窗和菜单限制在所属观测视图内。WebGL 初始化失败时仍可使用搜索、文件列表、检查和证据，错误提示提供恢复图谱入口。

面板采用不透底的 CSS 卡片，不再使用 SVG 背景或背景模糊。“主题 → 面板背景深度”调节固定底色的深浅；旧配置的 panelOpacity 值继续保留，并按背景深度解释。圆角、边框强度、字号和排版密度仍可分别调节。

蜘蛛巡查默认间隔 1.5 秒、同版本最早 30 秒复查，变化文件优先。它实际读取文件并使用 Babel / YAML 等解析器，不执行代码。支持的语法检查、frontmatter 和未解析链接会显示版本与 SHA-256；未支持类型、缓存待就绪和超限都显示具体原因。没有大模型调用。

业务检查沿用库内 v3 规范。引擎发生变化会显示需要 Actions 验证，插件不会执行新脚本。未知主目录进入图谱后仍可能未被业务引擎覆盖。“读取”“检查通过”和“理解内容”是不同事实，界面不把它们混为一谈。

智能体来源默认关闭。开启本地接收后只有配置好的来源会产生事件，接入方法见 `SOURCE-INTEGRATIONS.md`。这不会自动监听已有 Codex 会话，也不读取私人会话文件。真实 hook 配置仍留到候选批准后。

卸载时先关闭视图并禁用插件，再移除该插件目录。历史、布局和本地接收令牌都在其 state 目录，删除后无法恢复；插件不删除业务笔记。
