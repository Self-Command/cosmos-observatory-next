# 使用指南（开发候选）

候选审阅前不自动安装到真实知识库。最终 ZIP 完整解压到 vault 的 `.obsidian/plugins/cosmos-observatory-next/`；保留 assets 子目录和许可文件。仅复制 main.js 会丢失蜘蛛模型。

启用插件后，点击侧栏轨道图标，或执行命令“打开宇宙观测台”。一个 Obsidian ItemView 内显示宇宙与控制台，不启动网页服务。首次打开读取目录树和元数据并进行本地检查；日常文件变化自动更新，关闭全部观测视图会停止观察。

- 大球名称来自实际一级目录。空目录显示空态，新目录职责待确认。小球对应真实文件；隐藏数量表示显示预算，不是文件丢失。
- 拖动背景旋转镜头，滚轮缩放；排版开启后可选中世界标题或中心，直接拖动整球，也可用 XYZ 控件平移或旋转。锁定世界与锁定面板独立。
- 搜索文件后选择结果可展开目标，点击“打开文件”定位笔记。关系面板给出具体文件、原生链接或登记属性来源。
- 面板标题可以拖动，边与角可以缩放。标题按钮支持锁定、最大化与隐藏；底部可以重新显示。布局按当前 vault 保存。
- “动态”暂停视觉运动，“暂停巡查”停止新检查。历史滑块仅回放已经保存的证据；“返回实时”恢复当前观察。
- 设置包含配色、世界三轴布局、节点层数、浮动、线宽、背景、蜘蛛尺寸、巡查、模型路径、范围、面板和容量。分组可恢复默认。配置导出没有接收凭据。

蜘蛛巡查默认间隔 1.5 秒、同版本最早 30 秒复查，变化文件优先。它实际读取文件并使用 Babel / YAML 等解析器，不执行代码。支持的语法检查、frontmatter 和未解析链接会显示版本与 SHA-256；未支持类型、缓存待就绪和超限都显示具体原因。没有大模型调用。

业务检查沿用库内 v3 规范。引擎发生变化会显示需要 Actions 验证，插件不会执行新脚本。未知主目录进入图谱后仍可能未被业务引擎覆盖。“读取”“检查通过”和“理解内容”是不同事实，界面不把它们混为一谈。

智能体来源默认关闭。开启本地接收后只有配置好的来源会产生事件，接入方法见 `SOURCE-INTEGRATIONS.md`。这不会自动监听已有 Codex 会话，也不读取私人会话文件。真实 hook 配置仍留到候选批准后。

卸载时先关闭视图并禁用插件，再移除该插件目录。历史、布局和本地接收令牌都在其 state 目录，删除后无法恢复；插件不删除业务笔记。
